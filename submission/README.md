# GhostTrace

GhostTrace is a terminal deletion-audit predictor for the supplied participant dataset. Use Python 3.14 (tested on Windows with Python 3.14.3), install extraction dependencies with `python -m pip install -r code/requirements-extract.txt`, place the supplied `dataset/` beside `code/`, and run `python -B code/main.py --run --with-extraction` to write root `output.csv` (518 rows: 156 COMPLETE, 352 INCOMPLETE, 10 NOT_APPLICABLE). The final competition mode uses explicitly authorized heuristic defaults for missing policy conditions and retains uncertainty in JSON diagnostics; `--audit-policy --with-extraction` retains strict diagnostic behavior. Public development accuracy is 32/32 statuses and 9/32 exact rows; step recall is 158/193, with 542 tests passing. These are development measurements, not hidden accuracy or proof that every plan is correct. Runtime model calls and service cost are zero. Evaluate with `python -B code/evaluation/main.py --audit-samples --with-extraction` (exit 1 denotes imperfect exact-row agreement), test with `python -B -m pytest -q -p no:cacheprovider code/tests`, and package with `python -B scripts/package.py --prediction-mode --out submission-final`. Code archives exclude the dataset, caches, environments, traces and credentials; see `evaluation/evaluation_report.md` and `evaluation/usage_report.md` for measured results and assumptions.
