# Technical interview preparation — honest limits

These are preparation notes, not a transcript of a completed interview.

1. Architecture: a proof-carrying temporal compiler, not an agent swarm. The five
   existing stages separate input capture, historical evidence, policy, output and
   checks. The independent operation oracle has15 allowed operation triples.
2. Model/code seam: optional structured extraction supplies quoted facts; code
   validates them and applies policy. Recovery usedzero provider calls. A live
   model comparison is not available, and models cannot supply missing evidence.
3. Arbitration: group by resource and physical copy, filter both clocks, resolve
   each fact by observation time, preserve same-time conflicts. No universal SQL-
   beats-document priority is asserted. Missing facts remain UNKNOWN.
4. End to end: request authorization precedes identity; aliases retrieve global
   evidence; explicit links bind resources; replay evaluates audit_at; obligations
   generate typed operations; canonical emission and independent gates follow.
5. Retrieval: exact current/historical identifiers and bounded file/service/
   instance trace continuation. Resource-name suffixes do not prove ownership.
   Missing ownership of an absent/deidentified record remains a coverage limit.
6. Confidence: enum/Boolean prerequisites, not an LLM score or truthy prose.
   Zero unresolved in the historical candidate was insufficient evidence because
   defaults supplied missing facts; adversarial controls exposed this.
7. Workflow: Codex implemented earlier stages, Antigravity improved OCR/catalog
   parsing, and independent recovery rejected unsafe field/policy defaults.
   Authentic logs preserve both improvements and failures. No staged interview
   or retrospective conversation is claimed.
8. Trade-off: evidence safety can reduce published coverage. The historical
   baseline had518 internal decisions and only5/32 exact public rows; those are
   different metrics. Current results are in the canonical evaluation report.
9. Limits: missing pre-cutoff bindings/retention conditions; incomplete semantic
   interpretation; no hidden-label accuracy, live provider validation or verified
   final trace export. Official raw traces must be exported after sessions close.
